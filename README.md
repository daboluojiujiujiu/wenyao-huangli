# 问爻 · 黄历

在一块掌心大小的屏幕上，读一卦，查一天。

为 **M5StickS3** 编写的离线固件。问爻和黄历共用一个主菜单，两个按键就能操作。社区版不需要注册、联网或激活。

### 问爻

想体验三枚铜钱起卦，就从初爻开始摇六次；想研究某个组合，也可以选择上下卦，或从下往上自定六条爻。简单模式只看卦象和卦义，专业模式可以逐条读动爻的爻辞与象曰。自定六爻只供查阅，不覆盖上一次摇出的卦。

### 黄历

从当天的农历、干支和宜忌开始，也可以前后翻日，看一段简短解释。日期表保存在设备里；需要校时的时候，用手机连接设备热点即可，不用给设备输入家里的 Wi-Fi 密码。

### 第一次拿起来

菜单里 **B 切换，A 选定**。进入问爻首页，按住 B 约一秒即可切换简单与专业模式，不用等松手。其余操作可以在主菜单的说明书中随时查看。

当前公开源码基于二合一 **3.2.9**，问爻 **1.8.6**，黄历 **0.7.5**。只面向 M5StickS3，不适用于外形相近的 StickC Plus 或 ADV。
