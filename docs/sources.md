# 内容与出处

六十四卦与三百八十四条爻辞的经典文字，可对读[《周易》原典](https://zh.wikisource.org/wiki/周易)。界面中的现代解说不属于经文。这里提供传统文化阅读，不作现实决策保证。

农历表以 [lunar-javascript](https://github.com/6tail/lunar-javascript) 生成，支持 1900-01-31 至 2100-12-31。以北京时间计日，农历纪年按春节换年；宜忌为十二建除提示，不是完整逐日择日通书。[日历许可](licenses/lunar-javascript.txt)

中文字形来自 M5GFX 使用的 efont 系列，缺字子集沿用各组成字体的条款。[字形出处与许可](licenses/efont-upstream.md)
